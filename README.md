# PicoUI

A small library of themeable web components, built on [Lit](https://lit.dev).

## Demo

**https://js-works.github.io/picoui/**

Published from `src/demo` by
[`.github/workflows/deploy-demo.yml`](.github/workflows/deploy-demo.yml) on
every push to `main`.

## Development

```sh
npm install
npm run dev          # serve the demo with hot reload
npm run typecheck    # tsc, no emit
npm run build        # build the library into dist/
npm run build:demo   # build the demo into dist-demo/
npm run preview      # serve the built demo
```
